# Experience contribution and attribution — v0.1
Owner-directed working convention, 2026-11-26. House entry integration pending.

## During ordinary work
Search by problem or mechanism. If a prior experience influences work, record a reuse block in the actual work artifact at the time of use; append the outcome when known. Do not backdate, fabricate a reuse event, or treat reading as application. No extra report is required.

## At a meaningful new lesson or error
Record the original context, attempted method, failure (if any), correction, observed outcome, reason (distinguish inference), limitations and source evidence. Scientific/mathematical details belong in ARGO-Research; artistic details in the future artistic repository; transferable lessons belong here. If a specialized lesson may transfer, add a concise linked card, not a duplicate report. Retain the original and corrections. Keep private sources and mappings private unless publication is explicitly cleared.

## Copyable reuse block
See [template](templates/REUSE.md). Use ISO 8601 time with timezone; state unknown if unrecovered. Link an immutable source revision and the consuming artifact/evidence when available. Distinguish RETRIEVED, APPLIED_REPORTED, OUTCOME_EVIDENCED and INDEPENDENTLY_VALIDATED. Causal improvement needs a separate comparison; do not infer it from a link.

## Copyable lesson block
See [template](templates/LESSON.md). A human-readable note in the work is sufficient initially; a derived searchable card uses the existing JSON schema. No canonical promotion, new review committee or paid CI by default.
