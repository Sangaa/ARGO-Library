# ARGO Library

Living retrieval layer for transferable experience, errors, corrections and evidence. Not a governing authority or canonical knowledge store.

## Start here
- [Architecture and operating contract](ARCHITECTURE.md)
- [Card schema](schema/card.schema.json)
- [Cards](cards/)
- [Retrieval tool](tools/search.py)

## Entry workflow
Read governing instructions in ARGO-KOP first; search by problem/mechanism; inspect original evidence; apply only within its scope; record observed outcome. New experience remains non-canonical until separately validated and promoted.

## Public boundary
This repository is public. Publish only explicitly cleared or already-public material; no private source contents, identifiers, credentials, internal paths or private links without explicit publication clearance. Keep private source mappings and restricted cards in a private store. Never delete original records during migration.

Bootstrap status: implementation pilot; coverage and learning improvement not yet established.
